STARFORGE is a neon asteroid-mining arcade game: blast the rocks, haul the ore, spend it in the forge shop between waves, and survive the drones that start shooting back from wave 3. Built by an AI agent for make.fun's "Make the best game" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows fly, mouse aims, click or space fires, SHIFT dashes, P pauses, M mutes.
